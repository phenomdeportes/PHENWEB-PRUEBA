Emporium — Free Bootstrap 5 E-commerce Template
================================================

Emporium is a free, front-end e-commerce website template for broad, multi-category
online stores — electronics, home, fashion, sports, beauty and deals. It ships as a
working two-page storefront (a home page and a full product detail page) with a real
vanilla-JavaScript shopping cart: category filtering, a countdown Deal of the Day, a
slide-in cart drawer with a free-shipping progress bar, a product gallery with variant
options, keyboard-accessible tabs, a zoom lightbox and toasts. It is built on Bootstrap 5,
uses no jQuery, needs no build step, and is free for both personal and commercial use.

Get started: open index.html in a browser. Edit the HTML, css/style.css (design tokens
live in the :root block) and js/main.js to make it yours. Replace the placeholder images
in the img/ folder with your own at the same dimensions.
